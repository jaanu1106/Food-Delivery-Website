# 🍴 OnlineBhojan – Food Delivery Website

**OnlineBhojan** is a simple and responsive food delivery website designed to provide users with an attractive and user-friendly interface for exploring food delivery, dining, and different cuisine options.

## 🌟 Features

* 🛵 **Instant Delivery** – Quick and convenient food delivery service
* 🍽️ **Dining** – Explore dining options
* 🍕 **Multiple Cuisines** – Supports different food and cuisine options
* 🤝 **Our Clients** – Showcase of associated brands
* 📩 **Contact Us** – Contact form for user enquiries
* 📱 **Social Media Integration** – Links to social media platforms
* 🎨 **Responsive Design** – Simple and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Images & Icons** – Visual elements

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/jaanu1106/Food-Delivery-Website.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

## 🎯 Project Objective

The main objective of this project is to create a simple food delivery website while practicing fundamental **HTML and CSS web development concepts**, including page structure, styling, layouts, images, navigation, and responsive design.
